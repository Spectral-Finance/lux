# Cargo Package Management in Lux

`Lux.Rust.Cargo` provides a small Elixir-side package-management layer for Rust
projects owned by Lux. It generates Cargo manifests, normalizes dependencies,
plans build commands, and creates stable cache keys without requiring a Rust NIF
to be loaded first.

## Create A Manifest

```elixir
manifest =
  Lux.Rust.Cargo.new_manifest(
    package: %{name: "lux_native", version: "0.2.0", edition: "2021"},
    dependencies: %{
      serde: [version: "1", features: ["derive"]],
      serde_json: "1",
      rustler: [version: "0.36"]
    },
    features: %{default: ["serde/derive"]}
  )

File.write!("priv/rust/Cargo.toml", Lux.Rust.Cargo.to_toml(manifest))
```

Dependencies may be simple version strings or option lists/maps with `:version`,
`:path`, `:git`, `:branch`, `:tag`, `:rev`, `:features`, `:optional`, and
`:default_features`.

## Parse And Update Dependencies

```elixir
manifest =
  "priv/rust/Cargo.toml"
  |> File.read!()
  |> Lux.Rust.Cargo.parse_toml()
  |> Lux.Rust.Cargo.add_dependency(:serde_json, "1")
```

The parser is intentionally scoped to the manifest shape generated by Lux. That
keeps generated project management deterministic while avoiding a dependency on
a full TOML parser.

## Ensure A Project

```elixir
{:ok, manifest_path} =
  Lux.Rust.Cargo.ensure_project("priv/rust",
    manifest: manifest,
    force: false
  )
```

`ensure_project/2` writes `Cargo.toml` and `src/lib.rs` only when missing unless
`:force` is set.

## Build And Cache Plans

```elixir
plan =
  Lux.Rust.Cargo.command_plan("priv/rust", :build,
    profile: :release,
    features: ["nif", "serde"]
  )

cache_dir = Lux.Rust.Cargo.cache_dir("priv/rust", manifest)
```

Command plans are data maps with `:cd`, `:command`, and `:env`, so CI and Mix
tasks can decide when and how to execute Cargo. Cache keys are derived from the
package, dependency, dev-dependency, and feature coordinates.
